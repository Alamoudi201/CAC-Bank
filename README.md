# CAC BANK — مشروع البنية التحتية للشبكات والمراقبة الأمنية

**البنك التعاوني الزراعي — Cooperative & Agricultural Credit Bank**

---

## نظرة عامة

يشمل المشروع تصميم وتنفيذ شبكة داخلية (LAN/WLAN) عالية السرعة والاعتمادية وفق أعلى معايير الأمان المصرفي، إلى جانب نشر منظومة مراقبة مرئية (CCTV) ذكية ومربوطة بغرفة تحكم مركزية، لضمان حماية المقرات وسلامة العمليات المالية على مدار الساعة.

## نطاق العمل

- **تصميم وتنفيذ الشبكة الداخلية (LAN/WLAN)**: بنية تحتية سلكية موثوقة بمعايير Cat6 وCat6A لضمان سرعة واستقرار الاتصال بين الأقسام.
- **الأمان المصرفي**: تجهيز الشبكة وفق ضوابط تتناسب مع حساسية البيانات المالية.
- **منظومة المراقبة المرئية (CCTV)**: كاميرات مربوطة بمسجّل مركزي لتغطية المقرات على مدار الساعة.
- **غرفة تحكم مركزية**: تجميع نقاط الشبكة والمراقبة في خزائن (Racks) منظمة لسهولة الإدارة والصيانة.

## المكونات التقنية

بناءً على التنفيذ الفعلي الظاهر في الخزائن (Racks):

| المكوّن | الوظيفة |
|---|---|
| لوحات توزيع Cat 6A / Cat 6 (Purelink, D-Link) | توزيع نقاط الشبكة السلكية |
| مبدّلات شبكة Smart Link | ربط نقاط الشبكة الداخلية |
| جهاز Ubiquiti UDM Pro + مبدّلات USW Pro | إدارة الشبكة والتوجيه المركزي |
| مسجّل مراقبة Hikvision NVR | تسجيل وإدارة كاميرات المراقبة |
| تمديدات كابلات منظَّمة داخل خزائن مخصصة | ترتيب واحترافية التوصيلات وسهولة تتبع الأعطال |
